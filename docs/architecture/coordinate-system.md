# 坐标系统约定

本项目第一版统一使用“WGS84 原点 + 局部 ENU 坐标”，所有核心计算都在局部坐标中完成。

## 基本约定

| 项目 | 约定 |
|---|---|
| 全球参考 | WGS84，经度、纬度单位为度 |
| 地图内部坐标 | 局部 ENU 直角坐标 |
| X 轴 | East，向东为正 |
| Y 轴 | North，向北为正 |
| Z 轴 | Up，向上为正 |
| 距离、宽度、高度 | 米（m） |
| 速度 | 米每秒（m/s），界面可换算为 km/h |
| 航向角 | 弧度（rad） |
| 航向角零方向 | X 轴正方向，即正东 |
| 航向角正方向 | 逆时针 |
| 曲率 | `1/m` |

物流园教学地图暂定参考原点：

```text
longitude = 104.0668°
latitude  = 30.5728°
altitude  = 500.0 m
```

该原点只用于虚构教学场景，不代表真实园区测绘成果。每份地图都必须在 `MapHeader` 中保存自己的原点，禁止依赖程序中的固定常量。

## 航向角示例

```text
向东：0
向北：π/2
向西：π 或 -π
向南：-π/2
```

程序内部将航向角规范到 `[-π, π)`。

## 容差

数值误差和业务质检容差必须分开：

| 用途 | 首版默认值 |
|---|---:|
| 浮点数近似比较 | `1e-6` |
| 坐标点近似重合 | `1e-3 m` |
| 相连对象端点最大距离 | `0.50 m` |
| 编辑器吸附提示距离 | `0.30 m` |
| 连续曲线之间最大航向差 | `10°` |
| 涉及点列路径时最大航向差 | `30°` |

这些值是教学场景默认值，后续应通过规则配置调整，不能描述为量产地图标准。

## 使用限制

- 只有 `mapId` 和坐标参考一致的几何才能直接比较或合并；
- WGS84 与 ENU 的转换必须显式传入地图原点；
- JSON 和 C++ 都使用双精度浮点数保存生产地图坐标；
- 车端地图编译器以后可以按精度需求转换为浮点数或定点数；
- 本项目不处理跨城市、跨投影带和地球曲率显著的大范围地图。
