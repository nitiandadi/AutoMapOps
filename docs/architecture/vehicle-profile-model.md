# VehicleProfile 车辆模型

`VehicleProfile` 表示一类用于地图通行判断的车辆，而不是某一辆车的实时状态。

| 字段 | 单位 | 含义 |
|---|---|---|
| `id` / `name` | — | 稳定业务 ID 与显示名称 |
| `type` | — | `passenger_car`、`delivery_van` 或 `truck` |
| `width_m` | m | 必填车宽，是窄车道判断的基础输入 |
| `height_m` | m | 可选车高，用于限高判断 |
| `length_m` | m | 可选车长，用于空间和调头判断 |
| `minimum_turning_radius_m` | m | 可选最小转弯半径，用于连接几何可行性判断 |

模型只保存车辆事实，不直接提供 `can_pass()`：车道有效宽度、区域白名单、连接曲率等地图条件分散在不同对象中，应由 M3 质检或 M5 路由约束统一计算。缺失的可选尺寸表示“未知”，不能自动当作零。

首版不包含轴重、载重、坡度能力、动力类型和实时车辆状态；矿区扩展将在 M9 增加重载车辆约束。
