# AutoMapOps 项目管理总览

本文档用于回答两个问题：

1. 整个练手项目需要完成哪些阶段；
2. 当前真实做到哪一步，下一步应该做什么。

详细任务、依赖关系和验收条件见 [tasks.md](./tasks.md)。

## 项目目标

使用 C++ 为主要开发语言，实现一个面向物流园区、矿区等封闭场景的自动驾驶地图生产与车端交付平台，跑通以下闭环：

```text
首版地图草稿 V0
→ 地图编辑与拓扑构建
→ 规则质检
→ 正式 MapVersion V1
→ C++ 地图编译
→ MapPackage V1
→ C++ 车端 SDK 加载、查询与路径规划
→ Candidate Map Patch
→ MapVersion V2
→ 动态事件覆盖与重新规划
```

## 状态定义

任务只使用以下四种状态：

| 标记 | 含义 |
|---|---|
| `✅` | 已完成，并满足任务验收条件 |
| `🟡` | 正在实施，但尚未满足全部验收条件 |
| `⬜` | 尚未开始 |
| `⛔` | 被明确问题阻塞，需要先解决依赖 |

## 更新规则

每完成一个任务，应同步进行以下操作：

1. 在 [tasks.md](./tasks.md) 中更新任务状态；
2. 更新本页里程碑的“已完成/总任务”；
3. 把“当前下一步”移动到下一项未完成任务；
4. 在下面的进展记录中增加一条记录；
5. 如果设计发生变化，在记录中说明原因和影响范围。
