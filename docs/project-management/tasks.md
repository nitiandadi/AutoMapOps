# AutoMapOps 详细任务清单

本清单按真实依赖顺序拆分任务。每项任务必须产生明确的仓库成果，并满足对应验收条件后才能标记为完成。

## M0：项目定义与技术基线

目标：在写代码之前固定项目范围、职责和核心数据语言。

| 状态 | ID | 任务 | 产物或验收条件 |
|---|---|---|---|
| ✅ | M0-01 | 确定项目定位 | 面向封闭场景的地图生产与车端交付平台，平台侧约 70%，车端消费者约 30% |
| ✅ | M0-02 | 划分云端与车端职责 | 平台负责正式地图，车端负责实时消费和安全兜底 |
| ✅ | M0-03 | 确定主要开发语言 | C++ 为核心语言，TypeScript 仅用于 Web 前端，Python 仅作可选辅助 |
| ✅ | M0-04 | 区分地图生命周期对象 | 已区分 V0、MapVersion、MapPackage、Candidate Patch、ChangeSet、Dynamic Event |
| ✅ | M0-05 | 确定首版地图冷启动流程 | V0 草稿经过编辑、拓扑和质检后发布 V1，再编译成 MapPackage V1 |
| ✅ | M0-06 | 编写核心数据契约设计 | 已在 `docs/architecture/core-data-contracts.md` 中定义五类对象的字段、方向、状态、关系和约束 |
| ✅ | M0-07 | 编写坐标系统约定 | 已在 `docs/architecture/coordinate-system.md` 中明确 WGS84 原点、局部 ENU、单位、轴方向、航向角和容差 |
| ✅ | M0-08 | 冻结 MVP 范围和非目标 | 已在 `docs/architecture/mvp-scope.md` 中明确第一版必须完成、暂不实现和最终验收内容 |

M0 完成标准：核心设计进入仓库，后续代码可以只依据设计文档实现，不依赖聊天记录补充定义。

| ✅ | M2-02 | 实现 `MapHeader` | 已实现 map ID、名称、Schema 版本、WGS84 原点、ENU 坐标系、米/弧度单位约定、稳定名称转换和值比较 |
| ✅ | M2-03 | 实现道路和车道模型 | 已实现 Road 参考线及道路拓扑、Lane 中心线、相对侧别与层级、方向、状态、宽度、限速、边界和前后继引用 |
| ✅ | M2-04 | 实现边界模型 | 已实现独立 `LaneBoundary`、稳定类型名称、共享边界和统一几何方向约定，并显式区分边界形态与跨越权限 |
| ✅ | M2-05 | 实现路口模型 | 已实现 Junction 双向引用、入口/连接/出口 Lane 关系、转向类型、稳定名称和值比较 |
| ✅ | M2-06 | 实现场景对象 | 已实现带类型的 `OperationalArea`、可路由 `Station`、车辆白名单 `RestrictedArea` 及稳定名称 |
| ✅ | M2-07 | 实现车辆模型 | 已实现车辆类型、车宽及可选车高、车长、最小转弯半径等基础通行约束 |
| ✅ | M2-08 | 实现 `MapData` 聚合根 | 已按值持有九类地图对象，提供全部对象的可变/只读 ID 查询和整图值比较 |
| ✅ | M2-09 | 设计物流园道路拓扑 | 已完成 7 条 Road、12 条 Lane、1 个显式 Junction 的主路、装卸绕行、汇流与回程闭环，并包含仓库、月台、停车区、充电站和窄通道 |
| ✅ | M2-10 | 生成物流园 V0 草稿 | 已输出 `maps/drafts/logistics_park_v0.json` 和同目录中文说明，坐标、对象、道路级及车道级拓扑完整 |

M2 完成标准：V0 不是只有几何的 GeoJSON，而是一张包含明确坐标、属性、拓扑和业务对象的教学型车道地图。

|---|---|---|---|

| ✅ | M3-02 | 实现 Canonical JSON 写出 | 已支持格式化与紧凑写出，读写往返后整张 `MapData` 值一致 |
| ✅ | M3-03 | 实现 `inspect` 命令 | 已输出地图 ID、名称、Schema、坐标参考、WGS84 原点、ENU 范围和九类对象统计 |
| ✅ | M3-04 | 实现 ID 唯一性规则 | 已对九类对象执行全局唯一性检查，跨类型和同类型重复 ID 均产生 Fatal 问题 |
| ✅ | M3-05 | 实现引用完整性规则 | 已检查当前模型的全部显式 ID 引用，不存在的道路、车道、边界、连接、站点接入车道和车辆模型引用均产生 Error |
| ✅ | M3-06 | 实现基础几何规则 | 已检查点数、长度、相邻重合点、XY 自相交、区域闭合与面积、Lane 宽度、WGS84 原点和 ENU 坐标范围 |

## 明确不在首版范围内

以下内容不应在上述主线完成前插入：

- 真实 SLAM；
- 点云处理；
- 感知模型；
- 局部轨迹规划和车辆控制；
- 生产级多车地图融合；
- 增量二进制地图包；
- 多人实时协同编辑；
- 微服务和 Kubernetes；
- 量产级 OTA；
- 完整实现全部 OpenDRIVE 标准。
